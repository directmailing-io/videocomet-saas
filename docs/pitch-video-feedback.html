Video-Feedback für Master-Aufnahmen

Ein Frame.io-artiger Review-Link auf das Roh-Video — noch bevor eine Runde generiert wird. Absolut minimalistisch, sofort verständlich für Empfänger, mobile-first.

Konzept-Pitch Zielrelease: Etappe 1 (MVP) in ~1 Tag Basiert auf bestehender Share-Infra

Das Team

Product / UX Definiert Flow und Copy. Achtet auf den Oma-Test: jeder Button muss beim ersten Blick verständlich sein, auch für einen 70-jährigen Empfänger ohne Video-Tool-Erfahrung.
Frontend-Engineer Baut den Reviewer-Player, Timeline-Marker, Kommentar-Panel — reagiert 60fps auf Timeline-Klicks, funktioniert auf iPhone SE bis 4K-Desktop.
Backend-Engineer Zwei neue Tabellen, öffentliche API-Route, sitzt strikt auf der bestehenden Share-Cookie-Infra (kein zweites Auth-System).
Copywriter (Oma-Test) Textet alle Buttons, Toasts und Leer-Zustände so, dass niemand nachdenken muss. "Feedback geben" schlägt "Kommentar erstellen".

Was wir bei Frame.io gelernt haben

Kernidee (übernehmen)

  • Auto-Pause + Timestamp-Attach. Sobald der Reviewer ins Kommentar-Feld tippt, pausiert das Video und die aktuelle Zeit wird als Chip vor den Kommentar geheftet.
  • Marker-Bubble auf der Timeline. Jeder Kommentar wird als kleiner Kreis über der Playbar sichtbar. Klick springt zur Sekunde.
  • Toggle „nur allgemein". Kleiner Uhr-Schalter neben dem Senden-Button — aus = Kommentar ohne Zeitstempel (z.B. „Insgesamt zu lang").
  • Guest-Name inline. Erst beim ersten Senden fragt eine kleine Zeile „Wie heißt du?" — kein Login, kein Modal.

Bewusst weggelassen (kein Nutzen für unsere Zielgruppe)

  • Zeichnen aufs Video (Frame.io-Feature für Video-Editoren, nicht für Marketing-Empfänger)
  • @-Mentions, Hashtags, Filter, CSV-Export
  • Emoji-Reaktionen, Attachments, Version-Stacks
  • Vollwertige Reply-Threads (nur eine Antwort-Ebene reicht)

Der Flow

1. Ersteller: Link generieren — 15 Sekunden

Im bestehenden /kampagnen/[id]/bearbeiten ein neuer Tab „Feedback-Link" neben Video / Landingpage / PDF-Brief. Ein Button „Feedback-Link erstellen". Sofort erscheint eine Karte:

┌──────────────────────────────────────────────┐ │ Feedback-Link ist aktiv │ │ app.videocomet.de/review/a7f3-9k2m │ │ │ │ Läuft ab am 25.08.2026 · Kein Passwort │ │ [Kopieren] [QR-Code] [Passwort setzen] [Deaktivieren] │ └──────────────────────────────────────────────┘

Optional beim Erstellen: Passwort (falls sensibel) und Ablauf-Datum (Default 7 Tage). Beides änderbar, ohne den Link neu erzeugen zu müssen.

2. Empfänger: Feedback geben — sofort verständlich, kein Login

Der Link öffnet einen bildschirmfüllenden Player mit einer sehr reduzierten Kommentar-Spur:

╔══════════════════════════════════════════════════════╗ ║ ║ ║ [ Video 16:9, Sound aus ] ║ ║ ║ ║ ▶ ▬▬▬▬●▬▬▬▬▬●▬▬▬●▬▬▬▬▬▬▬▬▬▬▬ 01:23 / 02:45 ⚙ ║ ║ ─────────────────────────────────────────────────── ║ ║ ⏱ Bei 01:23 ┌──────────────────────────────┐ ║ ║ │ Ich finde den Übergang… │ ║ ║ └──────────────────────────────┘ ║ ║ [ Feedback senden ] ║ ╚══════════════════════════════════════════════════════╝ Unter dem Player (Desktop rechts, Mobile darunter): ┌──────────────────────────────────────┐ │ 3 Rückmeldungen │ │ ─────────────────────────────────── │ │ ● 00:12 Anna │ │ „Die Begrüßung wirkt gehetzt." │ │ │ │ ● 01:23 Anna │ │ „Ich finde den Übergang…" │ │ │ │ ● Allgemein Anna │ │ „Insgesamt super, danke!" │ └──────────────────────────────────────┘

3. Ersteller: Feedback sichten — gleiche Ansicht wie Empfänger

Der Ersteller sieht in einem eigenen Reiter „Feedback (3 neu)" exakt denselben Player, kann jeden Kommentar mit einem Häkchen als „Erledigt" markieren und (optional) eine Antwort schreiben, die der Empfänger beim nächsten Öffnen sieht.

Dashboard-Badge zeigt neue, ungelesene Rückmeldungen. Optional: Push-Benachrichtigung, sobald ein Kommentar reinkommt.

Der Trick: Zeitstempel greift „von selbst"

Der wichtigste Unterschied zu klassischen Chat-Feldern:

  • Empfänger klickt ins Feld → Video pausiert automatisch.
  • Über dem Feld erscheint der Chip ⏱ Bei 01:23. Klick auf das X macht den Kommentar allgemein.
  • Enter oder „Feedback senden" speichert. Marker erscheint sofort auf der Timeline.

Damit muss der Empfänger nichts lernen — er verhält sich intuitiv wie in einem Chat, und der Timestamp bleibt trotzdem präzise.

Optional in Etappe 2: Bereichs-Kommentare

Der User will explizit auch „01:23 bis 01:45"-Kommentare. Frame.io macht das mit gelben Klammern zum Ziehen — für unsere Zielgruppe zu Frickelig. Unser Vorschlag:

  • Neben dem Uhr-Chip ein zweiter Button „🕓 Bereich".
  • Klick → das Video pausiert am aktuellen Zeitpunkt und markiert Start. Play-Button startet, an gewünschter Endstelle noch mal auf „Bereich" → Ende.
  • Chip verwandelt sich in ⏱ 01:23 → 01:45. Marker auf Timeline wird zu einem gelben Balken statt Punkt.

Aus dem MVP rausgehalten, weil 90 % der Rückmeldungen mit Einzel-Timestamp auskommen. Sobald wir Bedarf sehen, in einem Tag nachziehbar.

Datenmodell (Migration 0059)

TabelleZweckKernspalten
video_feedback_links Ein Link pro Kampagne id, campaign_id, user_id, token (UNIQUE), password_hash (nullable), expires_at, revoked_at, created_at
video_feedback_comments Kommentare unter einem Link id, link_id, at_sec (float, nullable), at_end_sec (float, nullable, E2), author_name, body, resolved_at, owner_reply, created_at

Wieso zwei Tabellen statt einer? Damit ein späteres Deaktivieren oder Neu-Erzeugen des Links die Historie nicht killt — Kommentare bleiben am Link hängen, der Ersteller sieht sie auch nach Link-Ablauf im Dashboard.

Auth & Sicherheit

  • Token 16 Zeichen, base32-alphabet — nicht erratbar, gut per WhatsApp teilbar.
  • Falls Passwort gesetzt: identisches Muster wie /share/[token] (Argon2-Hash, signiertes Cookie vc_review_<prefix>, 24h TTL).
  • Rate-Limiting analog campaign_share_attempts (5 Fehl-Versuche / 15 min pro IP).
  • Middleware-Whitelist um /review/* und /api/review/* erweitert.
  • Reviewer-Name wird im Local-Storage gemerkt — beim zweiten Kommentar keine Frage mehr, aber ohne echten Session-Zwang.

Responsive-Verhalten

Desktop (≥ 1024 px):
  • Player links (max 900 px breit), Kommentar-Panel rechts (fest 360 px).
  • Timeline mit Marker-Bubbles fest unter dem Player.
Tablet (720–1023 px):
  • Player oben, Kommentare darunter als Karten-Stack.
Mobile (≤ 720 px):
  • Player fixed oben (16:9), Kommentar-Feld sticky am unteren Rand.
  • Kommentar-Liste scrollt zwischen Player und Feld.
  • Timeline-Marker vergrößern sich auf Touch-Zielgröße 32 px.
  • Timestamp-Chip ist Klick-Ziel — Tap öffnet den Kommentar-Sender im Vollbild-Bottom-Sheet.

Umsetzungs-Etappen

Etappe 1 — MVP (~1 Tag)

  • Migration 0059 (beide Tabellen)
  • Tab „Feedback-Link" in /kampagnen/[id]/bearbeiten
  • Public Route /review/[token] mit Player + Einzeltimestamp-Kommentaren + Name-Prompt
  • Ersteller-Ansicht (gleiche Komponente + Erledigt-Häkchen + Antwort)
  • Dashboard-Badge „N neue Rückmeldungen"
  • Responsive-Layouts

Etappe 2 — Bereichs-Kommentare + Push (~½ Tag)

  • Bereichs-Auswahl via „🕓 Bereich"-Button
  • Timeline-Balken statt Marker für Bereichskommentare
  • Optional Push-Nachricht ins Dashboard-Toaster bei neuen Kommentaren

Etappe 3 — Später falls gewünscht

  • Reply-Threads (mehrere Antworten pro Kommentar)
  • E-Mail-Digest an den Ersteller
  • Kommentar-Export
  • Video-Versionen (V1/V2 nebeneinander)

Was wir NICHT tun

  • Kein Zeichen-Tool. Nice-to-have für Cutter, unnötig für Marketing-Empfänger.
  • Kein Login. Link + optionales Passwort reichen.
  • Keine Video-Versionen im MVP. Wenn der Ersteller ein neues Video aufnimmt, überschreibt es das alte. Alte Kommentare bleiben mit „Bezieht sich auf Version vom 15.08." markiert.
  • Keine mobile App. PWA-Look reicht — der Link öffnet im Browser, Ende.
